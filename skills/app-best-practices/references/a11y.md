# Accessibility

Names, labels, contrast and titles.

13 rules: P0 0, P1 2, P2 10, P3 1.

## P1

- Give every IconButton a tooltip add-on; the icon is its only name otherwise.
- Replace an Image's seeded alt text "placeholder" with a real description, or empty alt for decoration.

## P2

- Icon Button Must Have Tooltip or Accessible Label.
- Set a document title on every page.
- Show a status with an icon or word besides colour; keep status colours out of chart series.
- Give images meaningful alt text, or empty alt if decorative.
- Action-only clickable text is a Button, not a Link without a url; a Link with no href cannot be reached by keyboard. (web only)
- Wrap custom CSS motion in @media (prefers-reduced-motion: no-preference). (web only)
- Name controls with additional.htmlAttributes aria-label rows; content.ariaLabel is not a block key.
- Give an AxisRichTextEditor standing in for a labelled input a content.ariaLabel; it renders no label of its own. (web only)
- Give MessageInput and CopilotInput actions a label; it is the button's accessible name and tooltip.
- Give an IconButton's slot-mode tooltip real words in content; an empty string announces nothing.

## P3

- Put a word beside an icon unless the icon is universal, such as search or close.
